Everything in Overclocked is done from the keyboard.

- **W A S D** - move your chef around the CPU.
- **E** - interact: pick up a brick, put it down on a station, or return it.
- **T** - *tick* the clock (five-stage levels only). Every press moves the whole pipeline forward one step.
- **F1** or the **?** button - open this tutorial at any time.
- **Tips** button - replay the level's step-by-step guide. Use **Back** / **Next** on a tip (or the **B** / **N** keys) to move between steps, **Done** on the last one, or **X** to hide it (Tips resumes where you left off).
- **Esc** - close this window. Press it during a level (with no window open) to quit to the main menu.

> The level timer is paused while this window is open.

## Jargon
- **Tick** - one clock cycle. The CPU does a little bit of work, then waits for the next tick.
- **Station** - a place in the world that stands for one part of the CPU.
