The overlay on top of the game tells you how you are doing.

- **Timer** (top left) - time remaining. Reach zero and the level is lost.
- **Progress** (below the timer) - instructions finished out of the total.
- **Instruction monitor** - shows what the current instruction is doing as it moves through the CPU.
- **Tips** button (top right) - replays this level's step-by-step guide. It is hidden while a tip is on screen, and only appears on levels that have tips.
- **Tip card** - shows "1 / N" with **Back** and **Next** (keys **B** / **N**); a pulsing ring marks the object the tip is about.
- **?** button (top right) - opens this tutorial.

## Jargon
- **HUD** - heads-up display: information drawn over the game world.
