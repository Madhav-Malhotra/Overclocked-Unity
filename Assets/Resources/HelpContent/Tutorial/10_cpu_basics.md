A **CPU** (central processing unit) is the part of a computer that runs programs. It repeats one simple loop billions of times per second: get an instruction, work out what it means, do it, and store the result.

This game uses **RISC-V RV32I**, a small, clean instruction set that is easy to learn.

## Jargon
- **Clock** - a steady pulse that tells every part of the CPU when to move on.
- **Instruction set (ISA)** - the list of instructions a CPU understands.
- **RISC-V** - an open, simple instruction set.
- **RV32I** - RISC-V with 32-bit numbers and basic integer instructions.
