Each **brick** is one program instruction, such as `addi x5, x0, 1`.

1. A brick appears on the glowing **start platform**.
2. Carry it through the CPU's stations.
3. Deliver it to the **end platform** once it has been fully processed.

Finish every brick before the timer runs out.

## Jargon
- **Instruction** - one tiny command a CPU can carry out, like "add two numbers".
- **Program** - a list of instructions executed in order.
